What each tweak does.

"Tweak" covers a lot of ground — a registry key, a scheduled task, a service tucked away in the background. Here's what each category actually changes on your machine, and why it's there.

⚡

Performance

Power plan settings, CPU parking, and background throttling. These tweaks stop Windows from quietly slowing your machine down to save a few watts it doesn't need to save on a desktop or plugged-in laptop.

🎮

Gaming

Input latency, GPU scheduling, and fullscreen optimizations. Aimed at shaving milliseconds off the path between your mouse and the frame on screen — the stuff that matters in competitive play.

🛡️

Privacy & Debloat

Telemetry, ad ID, and diagnostic data collection switched off, plus removal of preinstalled apps you never asked for. Nothing here touches security features like Defender or Windows Update.

🌐

Network

DNS, TCP window scaling, and background bandwidth throttling. These adjust how Windows negotiates and prioritizes your connection — useful on both slow links and fast ones.

🚀

Startup & Services

Trims what launches at boot and disables Windows services you're not using. The goal is a shorter path from power button to a usable desktop, not a stripped-down system that breaks things.

🎨

Customization

Taskbar, right-click menu, and File Explorer behavior. Mostly cosmetic, but it's the category people ask for most — small changes that make Windows feel like yours again.

How a tweak gets made

Every tweak starts as a specific, named problem — "Windows won't let me pick the Ultimate Performance plan," not "make my PC faster." We find the exact setting responsible, confirm it against official Microsoft documentation, and test it on a clean install before it's written up.

The write-up you see on the Tweaks page lists exactly what gets changed and how to revert it. If a tweak can't be cleanly explained or cleanly undone, it doesn't get posted — that rule doesn't bend for how impressive the result looks.

before you run a tweak

What to expect after downloading

Every Fear Studio tweak is a plain Windows Batch (.bat) file. Because batch files cannot be digitally signed like installers, Windows may display a security prompt before the tweak runs. This is normal behaviour for batch scripts.

🛡️ Open File - Security Warning

The publisher could not be verified. Are you sure you want to run this software?

Name C:\Users\Example\Downloads\FearStudioPowerPlan.bat
Publisher Unknown Publisher
Type Windows Batch File (.bat)
Location Downloads Folder
📄

Readable Code

Every tweak is written as plain text. You can right-click and open it with Notepad before running.

🔍

No Hidden Commands

There are no encrypted scripts or compiled executables—everything is visible and easy to inspect.

🌐

Open Source

Every tweak is available in the GitHub repository under the Tweaks folder so anyone can review the code.
