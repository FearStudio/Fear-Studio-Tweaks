before you click run

Why Windows shows a warning

Every Fear Studio tweak is a plain .bat file. Batch files can't be digitally signed the way commercial installers can, so Windows SmartScreen has no publisher certificate to check against — and shows this prompt by default. It's standard behaviour for any unsigned script, not a sign that something's wrong with the specific file.

How can I decide what software to run?

Not sure whether to trust it? Right-click any tweak and open it with Notepad first — every script is plain, readable text with no hidden or compiled code, and the full source is on GitHub. If you're happy with what it does, click Run to continue.

Common questions

Is this safe to run?

Yes — every tweak only touches the specific setting it describes. That said, registry and service edits are still system changes, so we recommend creating a restore point first if you're cautious.

Do I need to install anything?

No. Every download is a standalone file you run once. Then you press Number 1 to apply the tweak and watch the changes take effect.

Can I undo a tweak?

Yes. Each tweak includes a "revert" option that restores the original setting.

Why do some scripts need administrator access?

Anything that edits HKLM registry keys, Windows services, or system-level settings requires elevated permissions — that's a Windows requirement, not something specific to these scripts.

Will this work on my version of Windows?

Each tweak lists which Windows versions it's been tested on. Some features — like the taskbar "End Task" option — are Windows 11 23H2+ only and simply won't do anything on older builds.
