How it works.

Four steps between you and a faster, quieter Windows install. No installer, no account, no catch.

1

Browse tweaks

Filter by category — Performance, Gaming, Privacy, Network, Startup, or Customization — and find what fits your setup.

2

Download the file

Each tweak ships as a small .reg, .bat, or .ps1 file. No bundled installers, no extra downloads, no bloat.

3

Run it

Right-click and "Run as administrator" for .bat and .ps1 files. Double-click and confirm the prompt for .reg files.

4

Restart if needed

Most tweaks apply instantly. Some — like service or registry changes — need a restart to fully take effect.

🛡️

Every tweak is reviewed before it's posted

We check registry paths, service names, and script logic against official documentation before anything goes live. If a tweak changes a system setting, we tell you exactly what it touches — and how to reverse it if you change your mind.

Common questions

Is this safe to run?

Yes — every tweak only touches the specific setting it describes. That said, registry and service edits are still system changes, so we recommend creating a restore point first if you're cautious.

Do I need to install anything?

No. Every download is a standalone file you run once. Then you press Number 1 to apply the tweak and watch the changes take effect.

Can I undo a tweak?

Yes. Each tweak includes a "revert" option that restores the original setting.

Why do some scripts need administrator access?

Anything that edits HKLM registry keys, Windows services, or system-level settings requires elevated permissions — that's a Windows requirement, not something specific to these scripts.

Will this work on my version of Windows?

Each tweak lists which Windows versions it's been tested on. Some features — like the taskbar "End Task" option — are Windows 11 23H2+ only and simply won't do anything on older builds.
